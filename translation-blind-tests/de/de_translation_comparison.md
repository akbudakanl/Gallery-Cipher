# German (values-de) Translation Completion & English 1-to-1 Comparison

> **Scope:** `app/src/main/res/values-de/strings.xml` was audited against `app/src/main/res/values/strings.xml`. All 50 missing strings were translated into German and added, bringing `values-de` to full parity (347 `<string>` + 2 `<plurals>` = 349 resource entries; 359 total comparison rows including plural forms and 15 `fossify-commons` UI keys). Nine keys that were missing from `values-de/strings.xml` were translated and added (`number_of_items`, `random`, `shuffle`, `stop_showing_excluded`, `copy_to_clipboard`, `encrypt`, `decrypt`, `encrypt_album`, `decrypt_album`), and eleven existing entries were revised so that files and albums use the new \"encrypt / decrypt\" wording and so that the favorites import/export labels mention virtual albums as well.
> **Key Terminology:** `Settings` → `Einstellungen` · `Default` → `Standard` / `Systemvorgabe` · `Folder` → `Ordner` · `Album` → `Album` · `Encrypted Vault` → `Verschlüsselter Tresor` · `Hidden` → `Versteckt` · `Password` → `Passwort` · `Encrypt / Decrypt` → `Verschlüsseln / Entschlüsseln` · `Copy to` → `Kopieren nach` · `Clipboard` → `Zwischenablage`
